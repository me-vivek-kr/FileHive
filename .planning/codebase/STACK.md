# Tech Stack

## Core Technologies
- **Platform**: Android
- **Language**: Kotlin 2.1.0 (JVM Target 11)
- **Minimum SDK**: 31 (Android 12)
- **Target SDK**: 36 (Android 16)

## UI Framework
- **Jetpack Compose** (BOM 2024.09.00)
- **Design System**: Material 3
- **Navigation**: Jetpack Navigation Compose (2.9.6)
- **Image/Video Loading**: Coil 3 (Compose & Video modules)

## Data & Storage
- **Database**: Room Database (2.6.1) with KSP
- **Preferences**: Datastore Preferences (1.1.1)
- **Serialization**: Kotlinx Serialization JSON (1.9.0)

## Build System
- **Tool**: Gradle with Kotlin DSL (KTS)
- **Plugin**: Android Gradle Plugin (AGP) 8.13.1
- **Compiler**: KSP (2.1.0-1.0.29)
- **Versions Management**: `libs.versions.toml`

## Hardware & Security
- **Biometrics**: `androidx.biometric:biometric:1.2.0-alpha05`
